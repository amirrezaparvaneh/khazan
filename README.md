# لینکر | تحلیل پیشرفته لینک‌سازی داخلی وردپرس و ووکامرس (WILA)

یک افزونه مدرن و سریع برای تحلیل پیوند یکتا و معماری لینک‌سازی داخلی مقالات و دسته‌بندی‌های محصولات در وردپرس، با الهام از سیستم طراحی shadcn/ui و مجهز به موتور پیشنهادات هوش مصنوعی AvalAI با مدل DeepSeek Chat.

## امکانات کلیدی

- **اسکن دسته‌ای و غیرهمزمان (Batch Scanning):** تحلیل لینک‌های سایت در قالب صف‌های مجزا بدون افت سرعت یا خطای Memory Limit در سایت‌های بزرگ.
- **پشتیبانی بومی از ووکامرس:** تحلیل پیوندهای داخلی موجود در توضیحات دسته‌بندی‌های محصولات (`product_cat`).
- **تفکیک روابط لینک:** محاسبه مستقل پیوندهای ورودی (Inlinks)، پیوندهای خروجی (Outlinks) و انکرتکست‌های استفاده شده به همراه صفت‌های پیوند (`rel`).
- **کشف صفحات یتیم (Orphan Pages):** شناسایی فوری صفحات، مقالات و دسته‌بندی‌هایی که هیچ لینک ورودی ندارند.
- **پیشنهادات هوشمند AvalAI:** پیشنهاد صفحات کاندیدا، انکرتکست‌های بهینه، تعداد تکرار لینک و محل قرارگیری در محتوا با مدل `deepseek-chat`.
- **رابط کاربری مدرن:** کامپوننت‌های مینیمال با الهام از shadcn/ui، فونت اختصاصی وزیرمتن و فرمت کامل اعداد به فارسی.

## اصلاح انتخابی سئو در ویرایشگر

در ویرایش مقاله، برگه، محصول و دسته‌بندی‌های `category` و `product_cat` بخش «بررسی و اصلاح خوانایی و سئو» نمایش داده می‌شود. شروع بررسی، متن فعلی را به AvalAI ارسال می‌کند؛ کلید API باید در تنظیمات ثبت شده باشد. می‌توانید محدوده اصلاح را بنویسید، پیشنهادهای قبل/بعد را ببینید و فقط موارد دلخواه را تیک بزنید. اعمال تغییرات در ویرایشگر است؛ ذخیره با دکمه به‌روزرسانی وردپرس انجام می‌شود. بازگردانی آخرین اصلاح تا زمانی که متن دوباره تغییر نکرده باشد در دسترس است.

این قابلیت تحلیل مستقل هوش مصنوعی است، نه استخراج همه خطاهای داخلی Yoast. اصلاح جمله‌های بلند، شروع تکراری، مجهول و هدینگ مبهم پیشنهاد می‌شود؛ حفظ معنا نیازمند تأیید انسانی است. لینک‌ها و ساختار HTML عمداً تغییر نمی‌کنند. ویرایشگر کلاسیک و توضیح دسته‌بندی پشتیبانی می‌شوند؛ در گوتنبرگ فقط متن بلوک‌های استاندارد پاراگراف و هدینگ تغییر می‌کند. صفحه‌سازها، ویرایشگر جدید محصول ووکامرس، توضیح کوتاه محصول، متادیتا و بلوک‌های سفارشی در این مرحله پشتیبانی نمی‌شوند. حداکثر ورودی ۳۰۰ قطعه و ۸۰ هزار بایت JSON است.
